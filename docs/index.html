Notepad

A Reflect-style notetaking app: a daily-notes timeline, wiki-style [[backlinks]], private per-user accounts, and fully isolated notebooks.

View on GitHub Getting started

  • 🗓️ Daily notes

    Every day gets its own card in a reverse-chronological feed. Today is always ready to write in; page back through history whenever you like.

  • 🔗 Wiki-style backlinks

    Type [[Some Page]] in any note to link it. Each page shows every note that references it, with surrounding context.

  • ⌨️ [[ autocomplete

    Start typing [[ and pick from existing pages or titles you've referenced before — or create a new page inline.

  • 📚 Isolated notebooks

    Each notebook has its own daily feed, its own pages, and its own backlink graph. Notebooks never share links.

  • 🔐 Private accounts

    Register with email + password. Passwords are hashed with bcrypt; sessions use a signed, httpOnly JWT cookie.

  • 🪶 No build step

    Node.js + Express + SQLite on the backend, dependency-free vanilla JavaScript and CSS on the front end.

Run it yourself

Note: Notepad is a full-stack app (Express + SQLite), so this GitHub Pages site is just the project's landing page — the app itself runs wherever Node.js does. 

git clone https://github.com/PeytonFrankeCode/Notepad.git
cd Notepad
npm install
npm start   # then open http://localhost:3000 and sign up
